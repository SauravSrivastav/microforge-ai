# Contributing to MicroForge AI

Thank you for your interest in contributing. This project is a community-maintained playbook, and all improvements are welcome.

## What We Welcome

- **Prompt templates** — tested Claude Code prompts for different tool types (calculators, converters, generators, etc.)
- **AstroJS starter templates** — pre-configured with SEO, AdSense placeholders, and required pages
- **Documentation improvements** — corrections, clarifications, additional examples
- **Case studies** — real results from sites built with this workflow (anonymized stats are fine)
- **Alternative monetization guides** — affiliate marketing, freemium features, email capture
- **Language translations** — core guide in languages other than English

## What We Do Not Accept

- Guides for black-hat SEO techniques
- AI-generated content spam or low-quality bulk contributions
- Tools or workflows that violate Google AdSense or Search Console terms of service
- Affiliate links without disclosure

## How to Contribute

1. Fork this repository
2. Create a branch: `git checkout -b feat/your-contribution`
3. Make your changes
4. Commit with a clear message: `git commit -m "add: prompt template for unit converter tools"`
5. Push and open a Pull Request against `main`

## Guidelines

**For documentation:** Write in plain English. Short sentences. Practical examples over theory. Include timestamps or screenshots where relevant.

**For prompt templates:** Include the full prompt text, the tool type it targets, and any caveats about expected output quality. Test your prompts before submitting.

**For code templates:** Include a `README.md` inside the template folder explaining what it is and how to use it. Ensure it installs and builds cleanly with `npm install && npm run build`.

## Reporting Issues

Open a GitHub Issue with:
- What you expected to happen
- What actually happened
- Your environment (OS, Node version, Claude Code version)

## Code of Conduct

Be respectful. This community includes developers at all experience levels. Condescending or exclusionary language will not be tolerated.
